An open-world crime game in the spirit of GTA 6, built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC. Explore the sun-soaked city of Solara Bay on foot and by car, steal cars, dodge the police, run missions for the crew, and build your name from nothing to the biggest score the Bay has ever seen.

## Run it

Serve `game/` with any static file server and open `index.html` in desktop Chrome:

```sh
node serve.ts
# then open http://localhost:8080
```

No build step, no network requests, no install. Keyboard and mouse.

## How to play

- **WASD / arrows** — move on foot, drive when in a car
- **Shift** — sprint
- **E** — steal / enter / exit a car (hold E at a mission marker to do the job)
- **Mouse + click** — aim and shoot (once you have a pistol)
- **F** — punch
- **Esc / P** — pause, save, mute
- **M** — mute sound

Watch the wanted stars: the police come for car theft, assault and gunfire. Lose them by breaking line of sight, or lay low until the heat dies down. Complete all five story missions to finish the Bay Job.
